AtlasMMXXVI

AI agent configs drift apart.

Each agent stores its skills, instructions, memory, hooks and MCPs separately on every machine.

Atlas keeps one copy in git and syncs it everywhere.

How it works

  1. I

    Edit

    One web UI. Every save commits to git.

  2. II

    Sign

    A passkey tap signs each release.

  3. III

    Sync

    Local clients pull and write each agent's files.

Guarantees

  • Works offline

    Agents read local files. Hub downtime breaks nothing.

  • Your edits stay

    Writes only the config entries it manages.

  • Keys stay put

    MCP keys live in the keystore, not git.

  • Plain files

    Markdown and TOML in git. Undo any edit.

Status In development. The hub reads and edits everything today; machine sync is next.
