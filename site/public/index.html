How it works

  1. I

    Edit

    One web UI. Every save commits to git.

  2. II

    Sign

    A passkey tap approves each release.

  3. III

    Sync

    Clients pull releases into native agent files.

Guarantees

  • Stands offline

    Agents read local copies. Hub downtime stops nothing.

  • Managed entries only

    Your hand edits remain untouched.

  • No secrets in git

    MCP keys never leave the keystore.

  • Plain files

    Markdown and TOML in git. Every change is reversible.
