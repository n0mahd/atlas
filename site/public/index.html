ATLAS

Every AI agent keeps its own copy of your setup.

Skills, instructions, memory, hooks and MCP servers live apart in Claude Code, Codex, OpenCode, Pi and Antigravity, on every machine. Fix one and the rest drift. Atlas keeps one copy and carries it everywhere.

I

The problem

You improve a skill on your laptop. Your desktop still runs last month's. Codex never got it. Nobody can tell which copy is right.

II

How Atlas fixes it

One hub

Keeps everything

All your skills, instructions, memory, hooks and MCP servers, in git. One screen to read and edit them.

Every machine

Pulls the latest

A small client checks each signed release, then applies it.

Every agent

Gets its own files

Written in each agent's own format and folders. Nothing to patch.

III

A change, start to finish

  1. iEdit onceIn the hub, or in the file.
  2. iiCommitEvery save is a git commit you can undo.
  3. iiiSignOne passkey tap approves the release.
  4. ivArriveEvery machine and agent is current.
IV

What it promises

  • Nothing is lostEvery change is a commit. Roll back any time.
  • Works offlineAgents read local copies. If the hub is down, nothing breaks.
  • Your edits stayAtlas writes only the entries it manages.
  • Keys stay putMCP secrets live in the hub's keystore, never in git.
  • Plain filesMarkdown and TOML. Edit them by hand whenever you like.
