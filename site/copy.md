## 1. Hero (29 words)

### Headline options (pick marked)

1. **`AI agent configs drift apart.`** *(5 words — **PICK**)*  
   Concrete and unmistakable: names the exact domain ("AI agent configs", ruling out runtime agent orchestration) and the exact failure mode ("drift apart").

   Foregrounds the multi-machine dimension, but drops "AI" and leaves the reader to infer coding agents from the next line.
3. `Your AI agent configs drift.` *(5 words)*

## Cuts from the previous page (and why)

- **Merged "How Atlas fixes it" and "A change, start to finish" into one 3-step `How it works` section**: The previous page explained the same hub → signed release → client flow twice.
- **Cut "What it covers"**: Redundant. The hero already names all five config types (skills, instructions, memory, hooks, MCPs), and the before/after grid already names all five agents (Claude Code, Codex, OpenCode, Pi, Antigravity).
- **Cut the problem section's intro paragraph**: The hero states the problem and the grid proves it; a paragraph between them was filler.
- **Cut header tagline and footer slogan**: Decorative copy that added words without information.
- **Consolidated "Nothing is lost" and "Plain files" into one guarantee**: Git commit history is already stated in Step I (`Edit`) and reinforced in `Plain files` ("Markdown and TOML in git. Undo any edit."), keeping Guarantees to 4 sharp points.
